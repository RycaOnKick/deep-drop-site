# Deep Drop support site

Support page and privacy policy for Deep Drop by Tidewater Games, served with GitHub Pages.

- `index.html`: support page (contact and common questions). Use its address as the App Store "Support URL".
- `privacy.html`: privacy policy. Use its address as the App Store and Google Play "Privacy Policy URL".

Update `privacy.html` and its effective date before releasing a version that adds ads, analytics or accounts.
